### Featured Projects

**[Medical Telegram Warehouse](https://github.com/nardos-tsige/medical-telegram-warehouse)**
An end-to-end backend pipeline utilizing YOLOv8 image classification, FastAPI, dbt, and Dagster to process and serve public health data.

**[RAG Complaint Analyzer](https://github.com/nardos-tsige/complaint-analyzer)**
A RAG-powered chatbot using FAISS and Flan-T5, reducing financial complaint analysis time from days to minutes.

**[Socratic Mentor](https://github.com/nardos-tsige/socratic-mentor)**
An AI tutor that uses the Socratic method to guide students through discovery rather than giving direct answers. Built with React, TypeScript, and the Gemini API.
